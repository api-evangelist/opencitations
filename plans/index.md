# OpenCitations Plans

OpenCitations provides entirely free and open access to all of its APIs and datasets. There are no paid tiers, subscription plans, or commercial pricing models. The project is an open science infrastructure initiative operated by the Research Centre for Open Scholarly Metadata at the University of Bologna.

## Free Access (Default)

- Full access to the Index API (citation entities)
- Full access to the Meta API (bibliographic metadata)
- Full access to the SPARQL endpoints
- All data published under CC0 Public Domain Waiver
- No registration required for basic API access
- Rate limit: 180 requests per minute per IP address

## Access Token (Optional, Free)

Users are encouraged to obtain a free access token to help OpenCitations monitor usage metrics and demonstrate service value to funders and the research community.

- **Cost:** Free
- **How to obtain:** Submit your email at https://opencitations.net/accesstoken
- **Delivered:** Token sent to your email address
- **Privacy:** Email is not stored permanently; used only to deliver the token
- **Usage:** Include in the `authorization` HTTP header on all API requests

## Large-Scale Data Access

For bulk or large-scale data retrieval, OpenCitations provides database dumps rather than recommending heavy API usage:

- Download portal: https://download.opencitations.net
- Covers full dataset snapshots of COCI, Meta, and other indexes
- Free to download and use under CC0
